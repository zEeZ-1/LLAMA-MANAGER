## 复现方式

安装 README 中的后端开发依赖，构建前端后，用单独的浏览器验收环境运行：

```bash
uv venv /tmp/ascnet-browser
uv pip install --python /tmp/ascnet-browser/bin/python playwright==1.65.2
/tmp/ascnet-browser/bin/python -m playwright install chromium
/tmp/ascnet-browser/bin/python scripts/verify_ui_v32.py --dist frontend/dist
```

可以用 `--output /tmp/ascnet-v32-evidence` 保存截图与 browser.json。脚本自动选端口、建立临时工作目录并终止自己的测试服务，不提供连接生产后台的参数。`--backend-python` 可指定已安装后端开发依赖的解释器。

v3.1 的页面式界面回归脚本仅用于旧版，检出 `v3.1` 标签后运行。
