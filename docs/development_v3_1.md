# AscNet v3.1：工作空间界面更新

日期：2026-11-23。产品版本为 **v3.1**，前端包与后端健康接口版本为 **0.3.1**。API 路径继续使用 `/api/v1`。

## 目标与设计

项目对外名称更新为 AscNet。参考本机 EXO 的导航、深色中性色、黄色强调、紧凑状态信息以及会话 / 对话 / 计算资源分栏，按本项目的集中管理模式重新组织界面。AscNet 使用自己的 SVG 标志和组件，没有移植 EXO 的 Svelte 前端、自动组网或自动分片功能。

采用顶部全局导航，入口为总览、节点、模型、实例、对话。桌面在同一栏显示，手机采用品牌操作栏与导航栏两行排列。统一边框、卡片、状态、表单、空状态、失败提示与键盘焦点样式；不依赖远程字体、图片或新增组件库。

## 页面行为

| 页面 | 本版实现 |
| --- | --- |
| 总览 | 在线节点、系统内存总量、模型数量、就绪实例；控制节点与远端的管理拓扑；逐节点内存快照、后端 RSS；就绪实例入口与失败提示 |
| 节点 | 区分控制节点与 RPC 计算节点；紧凑硬件卡片、内存条；保留密码接入、指纹核验、配置详情以及 RPC 新建 / 部署 / 接管 / 启停 / 删除 / 日志 |
| 模型 | 模型包卡片；全部 / 图文 / 文本筛选；名称、路径及架构搜索；大小、变体与投影数量；可用性和识别原因；从卡片创建实例 |
| 实例 | 状态筛选与运行卡片；上下文、并发、GPU 层数及输入类型；设备分布、失败原因、详情与日志；就绪后进入对话；销毁后从当前列表移除 |
| 对话 | 可收起的左侧会话列表、中间聊天与右侧资源面板；快捷提问、实例选择；流式输出、停止、Markdown、图片上传 / 缩略图 / 预览及本地会话恢复 |

窄屏将会话与资源面板变为抽屉，支持背景遮罩、Escape 关闭和键盘焦点约束。抽屉打开时聊天区不可交互；调整窗口尺寸后恢复正常交互。已有操作弹窗统一支持焦点约束、关闭后的焦点返回和 Escape 调用可用的关闭按钮；进行中的操作仍服从原有按钮禁用逻辑。

创建实例仍使用真实可用的模型及设备，不添加模拟实例、虚假测速或下载入口。进入实例页时清除旧的状态筛选，避免从模型创建的新实例被此前的筛选隐藏。

## 指标口径

- 拓扑连线表示控制节点与远端的 SSH 管理关系，不代表模型分片、推理通信路径或实时流量。
- 系统内存总量仅相加在线、采样未过期且提供总量的节点；显示参与汇总的节点数量。共享 GPU 内存不额外累加。它不是可用显存或创建实例的容量承诺。
- 节点在线、RPC 就绪和 GPU 计算能力分别显示。GPU 未提供利用率或独立显存时不推导为不可用；共享内存设备继续显示“共享系统内存”。过期采样明确标记。
- 总览的管理后端 RSS 是该进程的采样值，不包含原生推理进程，也不等于整个管理层预算的合计值。完整预算仍以既有进程树测量脚本为准。

## 兼容与轻量约束

生产架构继续由 FastAPI 提供静态构建产物，无常驻 Node 服务，无新增前后端生产依赖。节点每 5 秒、实例每 2 秒的轮询集中在全局工作空间；子面板复用同一 React Query 缓存，避免重复设置节点和实例的轮询定时器。模型目录与任务 / 日志保留现有刷新方式；对话 Markdown 继续按需加载。

管理后端、启动包装进程、SSH、临时图片处理等辅助进程合计 RSS 目标仍为 **1 GiB 以内**；浏览器不计入；llama-server 和 RPC 的模型 / KV / GPU 分配另计。前端图形仅为 SVG、CSS 和既有图标，没有新增绘图库或远端管理 Agent。

品牌更新不重命名以下持久化或所有权标识：

- 浏览器 IndexedDB 数据库 `llama-inference-manager`，以及现有 version 2 的 sessions / messages / attachments 表。
- 服务端 SQLite、模型目录、配置键、实例 ID、SSH 专用密钥、远端服务名与 RPC 所有权。
- 仓库目录及现有启动命令。

图片继续二进制上传至媒体接口，对话 JSON 发送图片 ID；缓存、规范化图片、历史附件恢复和原生 file:// 注入沿用 V3 实现，不因换肤改变传输格式。

## 验收与发布

具体结果见 [v3.1 验证记录](validation_v3_1.md)。提供可选浏览器回归脚本 `scripts/verify_ui_v31.py`：自动建立临时数据库和微型 GGUF 包，启动隔离管理服务及确定性原生子进程，运行真实 HTTP 与浏览器链路；远端节点库存由浏览器路由生成测试数据，不连接真实 SSH。

构建产物放入 `frontend/dist/`，由正常启动的管理后台提供。发布仅更新静态文件及版本代码，不主动启动推理实例或远端 RPC；已有后台停机状态保持。没有引入数据库迁移或图片存储迁移。
