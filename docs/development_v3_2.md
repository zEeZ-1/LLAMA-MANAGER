# AscNet v3.2：常驻三栏工作空间

日期：2026-11-23。产品版本 **v3.2**，前端包与后端健康接口版本 **0.3.2**，API 保持 `/api/v1`。

## 交互结构

移除 v3.1 的总览 / 节点 / 模型 / 实例 / 对话全局导航和页面切换。参考 EXO，将工作组织为一个常驻工作空间：

| 区域 | 默认内容 | 操作 |
| --- | --- | --- |
| 左侧 | AscNet 标志、搜索、最近会话 | 新建 / 选择 / 删除会话；返回计算网络；流式生成期间标记当前会话并阻止切换 |
| 中间 | 控制节点与远端节点的管理拓扑 | 添加节点；点击节点进入该节点的完整控制详情；从左侧进入对话后显示聊天；随时返回节点 |
| 右侧 | 模型目录入口、实例列表与状态筛选 | 选择模型、填写参数、创建 / 删除实例、查看失败原因和日志；选择就绪实例开始对话 |

桌面没有顶部页面导航。会话、节点和实例面板分别滚动。打开节点控制详情只替换中间内容；开始对话只替换中间内容，左右两栏一直保留。

## 原功能入口迁移

| v3.1 入口 | v3.2 入口与保留内容 |
| --- | --- |
| 总览 | 中间计算网络：在线节点、系统内存总量、逐节点内存、就绪数量与管理后端 RSS；右侧直接展示实例状态 |
| 节点页 | 点击拓扑节点：完整硬件配置、GPU 与共享内存说明、SSH / 主机指纹、RPC 新建 / 部署 / 接管 / 启停 / 删除 / 日志 / 缓存及节点任务 |
| 模型页 | 右侧“模型目录”：类型筛选、搜索、自动扫描、手动刷新、变体 / 投影统计、不可用原因；选择模型后在右栏展开创建表单 |
| 创建实例弹窗 | 右栏内联表单：节点、模型、量化变体、输入类型、图文参数、单机 / 多机设备顺序与权重、实例名称、上下文与 GPU 层数；其余参数收进“更多推理参数” |
| 实例页 | 右侧常驻实例列表：状态筛选、上下文 / 并发 / GPU 层数 / 输入类型 / 设备、失败信息、详情日志、开始对话、销毁确认；已销毁实例继续不出现在当前列表 |
| 对话页 | 左侧会话列表 + 中间聊天：就绪实例选择、Markdown、推理过程、SSE、停止、图片上传 / 预览与历史附件恢复 |

创建提交期间禁止用新建或模型目录入口替换当前表单，避免丢失进行中的请求。明确选择模型时重置模型相关的变体、revision、输入类型和视觉设备字段；数值推理参数可继续编辑。再次从模型目录选择模型会建立新的创建草稿，不沿用另一模型的隐藏状态。

## 会话与草稿生命周期

- 会话列表通过既有 Dexie 的 liveQuery 监听 IndexedDB，不额外轮询服务端，也不新增依赖。
- Chat 在切换至节点时保持挂载，保留输入、附件、消息与当前流。用户仍可返回当前对话并停止生成。仅更换中间视图不会取消推理。
- 生成或图片上传期间禁止切换 / 删除 / 新建会话或通过另一实例切换对话，避免请求与界面对应错误；节点查看和实例控制仍可使用。
- 右侧创建表单在关闭手机抽屉时保留；重新打开继续编辑。明确取消或创建成功后才清除。
- IndexedDB 名称仍为 `llama-inference-manager`，沿用 version 2 表结构与历史消息 / 图片 Blob。没有服务端数据库迁移或节点身份变更。

## 窄屏

宽度不超过 1180 CSS px 时，会话列表变成左侧抽屉；不超过 900 px 时，实例管理变成右侧抽屉。窄屏顶部仅有品牌与打开左右栏的按钮，不引入另一套页面导航。

抽屉支持遮罩、Escape 和 Tab / Shift+Tab 焦点循环。中间区域在抽屉打开时不可交互；调整尺寸会关闭抽屉并恢复交互。实例详情、模型目录、SSH / RPC 操作和图片预览继续使用既有可访问弹窗行为。

## 资源与实现边界

继续由单个 FastAPI 服务提供静态构建产物；无新增生产依赖、常驻 Node 进程、远端 Agent 或图形库。节点 / 模型 / 实例仍由工作空间统一维护查询与轮询；节点任务在中间切换为聊天时暂停定时刷新。

保留后台管理层合计 RSS **低于 1 GiB** 的目标，浏览器不计入，原生推理资源另计。此次是前端结构调整，后端仅更新版本。二进制图片上传、媒体缓存、图片 ID 对话及 file:// 原生注入均不变。

拓扑只表示管理关系，不宣称实时推理流量。内存总量仅统计在线、采样未过期且提供总量的节点，GPU 共享内存不重复相加；“节点在线”不等于 GPU 计算验证通过。
